# 🚢 무역왕!

6개 나라(모둠)가 실시간으로 물건을 사고팔며 부족한 물건을 수입하고, 경제를 3단계까지 발전시키는 교실용 무역 시뮬레이션 웹앱입니다.
초등 6학년 사회 「세계 여러 나라의 무역: 상호의존과 경쟁」 수업용으로 만들었습니다.

## 1. 실행하기 (교사 컴퓨터 1대)

1. [Node.js](https://nodejs.org) LTS 버전(18 이상)을 설치합니다.
2. 이 폴더에서 터미널(명령 프롬프트)을 열고 아래 두 줄을 입력합니다.

```bash
npm install
npm start
```

3. 화면에 이런 주소가 나옵니다.

```
🚢 무역왕! 서버가 켜졌어요.
   이 컴퓨터:  http://localhost:3000
   학생 기기:  http://192.168.0.23:3000
```

- 선생님은 `http://localhost:3000` 으로 접속합니다.
- 학생 기기(태블릿·크롬북·휴대폰)는 **같은 와이파이**에 연결한 뒤 `학생 기기` 주소로 접속합니다.
- 학생 기기에서 접속이 안 되면 Windows 방화벽에서 Node.js 허용을 눌러 주세요.

## 1-1. GitHub + Render로 인터넷에 배포하기

이 앱은 실시간 동기화 서버(Node.js)가 필요해서 **GitHub Pages에서는 작동하지 않습니다.**
코드는 GitHub에 두고, 서버는 무료 호스팅 Render에서 실행합니다.

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `trade-king`)
2. **Add file → Upload files**를 누르고, 압축을 푼 `trade-king` 폴더 **안의 파일과 폴더 전부**를 끌어다 놓은 뒤 Commit 합니다.
   저장소 첫 화면에 `server.js`, `package.json`, `public` 폴더가 바로 보여야 합니다.
3. [render.com](https://render.com)에 GitHub 계정으로 가입합니다.
4. **New → Blueprint**를 누르고 방금 만든 저장소를 고릅니다. `render.yaml` 설정이 자동으로 적용됩니다.
   (또는 **New → Web Service**에서 Build Command `npm install`, Start Command `npm start`로 지정)
5. 몇 분 뒤 `https://trade-king-xxxx.onrender.com` 같은 주소가 생깁니다. 이 주소를 학생들에게 알려 주세요.

**무료 요금제 주의사항**
- 15분 동안 아무도 접속하지 않으면 서버가 잠들고, 다시 깨어나는 데 1분 정도 걸립니다. **수업 5분 전에 선생님이 먼저 접속**해 두세요.
- 서버가 잠들거나 다시 배포되면 저장된 게임방이 사라집니다. 수업 한 차시 안에서 쓰기에는 문제가 없습니다.
- GitHub 저장소의 파일을 고치면 Render가 자동으로 다시 배포합니다.

## 2. 수업 진행 순서

| 단계 | 선생님 | 모둠 |
|---|---|---|
| 준비 | **새 게임방 만들기** → 방 코드와 6개 모둠 코드가 나옴. **코드 카드 인쇄**로 나눠 주기 | 방 코드 + 모둠 코드로 입장 (계정 필요 없음) |
| 탐색 | (준비 중 상태) | 경제 발전 사다리에서 우리 나라에 부족한 물건 1~3번 확인, 세계 여러 나라 창고 살펴보기 |
| 무역 | **무역 시작**, 제한시간(3/5/10분) 설정 | 물물교환·현금거래 제안 보내기, 받은 제안 수락·거절 |
| 발전 | 필요하면 **생산 라운드**로 모든 나라 물건 +1 | 수입한 물건으로 1번부터 차례대로 **해결하기** → 경제발전 +1단계, 국가 자산 +1조원 |
| 정리 | **게임 끝내기** → 결과 발표, 무역 연결망·경쟁 보드로 토의 | 정리 질문에 답하기 |

## 3. 게임 규칙

- 시작 국가 자산: 나라마다 **1조원** (돈 단위는 억원)
- 부족 물건은 **1번 → 2번 → 3번 순서**로만 해결할 수 있고, 정해진 **개수를 모두 모아야** 해결됩니다.
- 해결하면 모은 물건을 사용하고, **경제발전 1단계 + 국가 자산 1조원 + 시민 만족도 20%**가 늘어납니다.

| 나라 | 풍부한 자원 (시작 수량) | 부족한 자원 (필요 수량) |
|---|---|---|
| 빨강 | 석유 10, 소고기 7 | 1. 옷 4 · 2. 핸드폰 3 · 3. 자동차 5 |
| 파랑 | 핸드폰 4, 컴퓨터 6, 배 4 | 1. 석유 5 · 2. 바나나 3 · 3. 와인 4 |
| 노랑 | 쌀 4, 바나나 5, 고무 5 | 1. 컴퓨터 5 · 2. 와인 3 · 3. 옷 4 |
| 초록 | 쌀 4, 바나나 4, 와인 7, 소고기 3 | 1. 배 5 · 2. 고무 4 · 3. 커피 3 |
| 보라 | 옷 5, 배 4, 자동차 8, 컴퓨터 3 | 1. 쌀 6 · 2. 커피 4 · 3. 석유 5 |
| 분홍 | 옷 5, 커피 7 | 1. 소고기 6 · 2. 자동차 3 · 3. 바나나 4 |

- 석유·와인·자동차·커피는 공급 = 수요라서 **사려는 나라끼리 경쟁**합니다.
- 옷·배·쌀·바나나·컴퓨터·소고기는 공급 > 수요라서 **파는 나라끼리 경쟁**합니다.
- 핸드폰·고무는 한 나라만 팔고 한 나라만 사는 **1:1 의존** 관계입니다.

### 시민 만족도 (0~100%)

무역은 나라 경제뿐 아니라 시민(소비자)에게도 이익을 줍니다.

| 오르는 때 | 변화 | 최대 |
|---|---|---|
| 부족 물건 문제를 해결할 때 | +20% | 60% |
| 필요한 물건을 기준 가격(1개 1,000억원)보다 싸게 수입할 때 | 아낀 100억원마다 +1% | 40% |

- 물물교환은 주는 물건을 1개 1,000억원으로 계산합니다. (예: 석유 1개를 주고 옷 2개를 받으면 1,000억원을 아낀 셈)
- 우리 시민에게 필요한 물건만, 필요한 개수까지만 계산합니다.
- 비싸게 사도 만족도가 내려가지는 않습니다.
- 순위는 경제발전 단계로 정하고, 시민 만족도 1등은 결과 발표에서 따로 알려 줍니다.
- 순위: 경제발전 단계 → 국가 자산 → 먼저 달성한 순
- 거래 종류
  - **물물교환**: 물건 ↔ 물건
  - **현금거래**: 물건 ↔ 돈
  - **물건+현금**: 섞어서 제안 가능
- 모든 거래는 서버가 확인합니다. 수락하는 순간 양쪽 창고가 부족하면 거래가 이루어지지 않습니다.

## 4. 학습 목표와 연결된 화면

- **의존** — 선생님 화면의 *무역 연결망*: 나라 사이 선이 굵을수록 많이 거래했어요. 모둠 화면의 사다리에는 “지금 가진 나라”가 떠서, 우리 문제를 해결하려면 다른 나라가 필요하다는 것을 바로 볼 수 있어요.
- **경쟁** — 선생님 화면의 *경쟁 보드*: 옷·배·쌀·바나나·컴퓨터·소고기는 파는 나라가 둘(판매 경쟁), 석유·자동차·와인·커피는 사려는 나라가 파는 나라보다 많아요(구매 경쟁).
- **소비자의 이익** — 판매 경쟁 상품은 싸게 살 수 있어 시민 만족도가 오릅니다. 제안 화면에 1개당 값과 기준 가격이 함께 표시됩니다.
- 게임이 끝나면 모든 화면에 결과와 정리 질문이 나옵니다.

## 5. 우리 반에 맞게 바꾸기

`game-data.js` 파일만 고치면 됩니다.

- `startInventory`: 나라별 시작 물건 수량
- `needs`: 부족 물건 1~3번, 필요 수량(`qty`), 설명
- `SETTINGS.startCash`, `SETTINGS.levelBonus`: 시작 자산, 단계별 보너스 (10000 = 1조원)
- `SETTINGS.basePrice`, `satPerStage`, `savingPerPoint`, `satSavingMax`: 기준 가격과 시민 만족도 규칙

## 6. 파일 구조

```
trade-king/
├─ server.js        게임 서버 (방·거래·경제 발전 규칙, 실시간 동기화)
├─ game-data.js     나라·물건·설정 데이터
├─ package.json
├─ render.yaml     Render 배포 설정
├─ public/
│  ├─ index.html    화면 틀
│  ├─ app.js        모둠 화면 + 선생님 화면
│  └─ style.css     디자인
└─ data/rooms.json  (자동 생성) 서버를 껐다 켜도 게임이 이어지도록 저장
```

## 7. 자주 묻는 질문

- **학생이 새로고침하거나 기기를 바꾸면?** 같은 방 코드·모둠 코드로 다시 들어오면 그대로 이어집니다. 한 모둠이 여러 기기로 동시에 들어와도 모두 같은 화면이 동기화됩니다.
- **선생님 화면을 닫았다면?** 첫 화면의 “최근에 만든 게임방 → 다시 열기”를 누르세요 (같은 브라우저에서).
- **실제 카드와 숫자가 안 맞으면?** 선생님 화면의 🛠️ 조정으로 창고·자산을 고칠 수 있습니다.
- **모둠 코드가 칠판 화면에 보이면 곤란해요.** 기본은 가려져 있고 🔑 버튼을 눌러야 보입니다.
